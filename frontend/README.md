# PrismDesk 客服台（前端）

Vue 3 + Vite。打包结果输出到 `src/main/resources/static/`，由 Spring Boot 直接托管：
启动后端后打开 **http://127.0.0.1:8080/** 就是客服台，和接口同源，不需要额外的容器、Nginx 或跨域配置。
打包好的文件已经提交在仓库里，**只运行后端不需要装 Node**。

## 三种角色看到的页面

| 角色 | 页面 |
|---|---|
| 客户 | 咨询客服：发消息时实时显示"理解你的问题 / 查找相关资料 / 组织回答"等进度；转人工后，坐席接手会在对话里提示 |
| 坐席 | 工单（新工单实时弹出、抢单、解决）、对话记录（任意客户的对话，每条回复的处理过程图）、知识库检索 |
| 管理员 | 坐席的全部 + 知识库维护、运行状态、账号管理 |

"处理过程"图把一轮对话的各环节耗时按真实先后关系画在一条时间轴上：
记忆 → 意图识别 ‖ 知识库检索（并行，虚线框）→ 生成 → 校验 → 落库 → 建单。降级的环节用斜纹标出。

## 登录状态

- 访问令牌只放在内存里；刷新令牌放在 localStorage，刷新页面后用它换回登录状态。
- 每次请求前，如果访问令牌还剩不到 60 秒就先刷新；多个请求同时需要刷新时，只发一次刷新请求（刷新令牌是单次使用的）。
- 流式对话和实时通知用 fetch 读取 SSE，而不是 EventSource：EventSource 不能带 `Authorization` 头。

## 修改前端

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173，接口代理到 http://127.0.0.1:8080
npm run build    # 输出到 ../src/main/resources/static/，然后重新构建后端镜像
```
